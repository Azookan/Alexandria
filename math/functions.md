Before we define a function, we need to be familiar with sets. A set is just an unordered collection of objects. To define a set, we can use words or we can list everything inside the set. For example, R = 4 is the set named R which contains the numbers 1, 3, and 4. We use the curly brackets to say that we're talking about the set. Also, any member of a set is called an element. So, 1 is an element of R.

A Cartesian product is a special kind of action we do with sets. The Cartesian product allows us to build new sets by picking a combination of elements from two sets. For example, let's look at a new set 7. 2x7 is a Cartesian product. It is the set of all pairs that we can create by selecting an element from each set. This means (1,6), (2,6), (1,7), and (2,7) are all included in the Cartesian product.

Finally, we have functions. Functions are ways to relate one set to another set. For example, we can define a function f that accepts any whole number (in the set of whole numbers) and associates it with its negative version. We can think of functions as inputting something to output something. For instance, f(1) = -1, f(2) = -2, and so on. Notice how functions define Cartesian products by creating pairs like (1,-1), (2,-2), and so on.
