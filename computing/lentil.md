Lentil is a program to resolve type A corruption with files. We say that the corruption is of type A if Lentil is able to recover it. Some files are too corrupted for Lentil to go through. As a protective measure, Lentil also prevents the user from reading files which are not of a type A corruption (such as files which are not corrupted to begin with).

Syntax usage: run lentil on \<filename\>
